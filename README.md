**JarkViewer** 是一款简约且飞快的 Windows 看图软件。从 JPEG 到 AVIF、HEIC、JPEG XL 等最新格式都能打开，RAW、动图、iOS 实况照片与 Android 动态照片也流畅浏览；视频与音频交给内置的独立播放器，支持进度拖动、音量调节、实时频谱与媒体信息面板。

单文件绿色免安装，全部依赖静态链接，双击即可用。

![Preview](preview.png)

## ✨ 看图操作

| 操作 | 方式 |
| --- | --- |
| 切换图片 | 窗口左右边缘 `单击/滚轮`、`←` `→`、`PgUp` `PgDn`、`空格`（静态图时切下一张） |
| 缩放 | 窗口中间 `滚轮`、`↑` `↓`；`5`（数字小键盘 `5`）在 `1:1` 与「适应窗口」之间切换 |
| 旋转 | 窗口左上角或右上角 `单击/滚轮`、`Q` `E` |
| 平移 | 鼠标拖动、`W` `A` `S` `D` |
| 图像信息（EXIF） | 鼠标 `中键单击`、`TAB` 或 `I` |
| 全屏 | `双击窗口`、`F`、`F11` |
| 幻灯片播放 | `P`（`ESC` 停止）；顺序与间隔在设置页调整 |
| 动图逐帧 | 窗口顶部控制栏、`J` 上一帧 `K` 暂停/继续 `L` 下一帧 |
| 首页 / 末页 | `Home` / `End` |
| 删除 | `Delete`（移到回收站，可在设置里关掉确认提示） |
| 打开图片 | `Ctrl + O`，或把文件拖进窗口（一次拖多个时只取第一个，之后可在同目录翻页） |
| 复制图像 | `Ctrl + C` |
| 打印 | 窗口左下角 `单击`、`Ctrl + P` |
| 编辑与标注 | `Ctrl + E` |
| 批量处理 | `Ctrl + B` |
| 重命名 | `Ctrl + R` |
| 分解动图 | `Ctrl + S` 把动图每一帧另存为单独的 PNG |
| 设置 | `F1` 常规、`F2` 文件关联、`F3` 帮助、`F4` 关于 |
| 退出 | `ESC`、`Ctrl + W` |

其他好用的地方：

- **右键菜单**：复制 EXIF 信息 / 文件路径 / 图像数据、导出视频、显示 EXIF、打开所在位置、重命名、复制或移动到目标文件夹、用外部编辑器打开、删除到回收站、文件属性、打印、编辑、幻灯片、批量处理、全屏、设置、关于。
- **悬停缩略图带**：鼠标移到窗口底部会展开同目录的缩略图带，滚轮或左右键翻页、点击直接换图；移开自动收起。
- **鸟瞰图**：右下角显示整图与当前可见区域，拖动方框即可快速定位到图片的任一角落；不需要时按面板上的 `✕` 收起（设置页也能开关）。

## 🎬 播放器（视频 / 音频）

命令行、拖放或用「打开」选中视频或音频文件，会进入独立的播放器窗口（不影响看图功能）：

| 操作 | 方式 |
| --- | --- |
| 播放 / 暂停 | `空格`，或 `单击画面` |
| 前后 5 秒 | `A` `D`、`←` `→` |
| 音量 | `W` `S`、`↑` `↓`、`滚轮` |
| 单帧步进 | 暂停状态下 `A` `D`、`←` `→`（音频没有画面，按 5 秒跳转） |
| 开头 / 结尾 | `Home` / `End` |
| 进度跳转 | 拖动底部进度条（拖动中显示关键帧预览，松手精确落位） |
| 媒体信息 | `I` 或 `TAB`（路径、大小、时长、容器、总码率、视频与音频的编码参数） |
| 全屏 | `双击画面`、`F`、`F11` |
| 换片 | `Ctrl + O`（选到图片会交回看图窗口） |
| 退出 | `ESC`、`Ctrl + W` |

- **音频文件没有画面**：窗口里显示文件名与路径，并带一列**跟着声音实时跳动的频谱条**，进度条常驻显示。
- **播完停在最后一帧**，再按 `空格` 从头重播；进度条拖到哪儿就精确跳到哪儿。

## 🖨 打印 / 编辑

`Ctrl + P` 进入打印预览，可以调整 `对比度`、`亮度`、`是否反色`，选择颜色模式：`彩色`、`黑白`、`黑白文档`、`黑白抖动`，再决定 **另存为** 其他图像文件或 **继续打印**。

1. **黑白文档**: 均衡全图亮度，突出字迹，避免局部阴影的观感影响，适合打印拍摄的文字纸张图像。
2. **黑白抖动**: 使用纯黑像素的分布密度模拟像素灰度值。此模式适合针式打印机和热敏打印机，也能打印出较好的图像效果。

`Ctrl + E` 进入编辑与标注：矩形、椭圆、箭头、直线、画笔、马赛克、文字，可调颜色、线宽、字号与填充；支持撤销重做、旋转/翻转/反相、裁剪，完成后可另存为、复制到剪贴板，或直接覆盖原文件（PNG 保留透明通道，JPG 的透明区域会铺白底）。

## 🗂️ 批量处理

`Ctrl + B` 打开批量处理，对当前目录的图片一次做完：

- **转换格式**：HEIC / AVIF / RAW 等也能参与转换，输出 JPEG、PNG、WebP、BMP、TIFF…
- **缩放**：按百分比、按宽度、按高度、自定义宽高（可拉伸）、限制长边（只缩不放），重采样算法默认自动（缩小用面积平均、放大用 Lanczos）
- **旋转 / 翻转**
- **重命名**（前缀 + 序号）
- 可选亮度、对比度与颜色模式调整；支持指定输出目录或就地输出、选择是否覆盖同名文件

## ✏️ 文件管理与格式关联

- **重命名**（`Ctrl + R`）：只改文件名主体，扩展名不动；会校验空名、非法字符、保留设备名、同名冲突。
- **复制 / 移动到目标文件夹**：目标目录可随时切换，重名自动让到 `名称 (2).ext`，从不覆盖；跨盘移动自动退化为复制 + 删除。
- **外部编辑器**：把当前图片交给指定程序打开（程序路径可设置），点击即用。
- **删除到回收站**：不会真正删除文件，可在设置里关掉确认提示。
- **资源管理器缩略图**：随程序附带的 `JarkThumbnailProvider.dll` 可为 `JXL / AVIF / HEIC` 等格式在资源管理器中提供缩略图。在设置页「文件关联」里勾选想要的格式并应用，程序会一并注册文件关联与缩略图（DLL 不在程序目录时自动跳过）。
- **文件属性**：直接调出系统的属性对话框。

## 📹 实况照片与导出视频

- **实况照片**：iOS 的 `livp`、Android 的 MicroVideo / MotionPhoto（`jpg`/`heic`/`heif`）都能识别，打开后自动播放一次，然后回到静态图；`空格` 可随时重播。是否播放声音由设置页「实况自动播放声音」决定（默认静音）。
- **导出视频**：右键菜单「导出视频」把实况照片内嵌的视频**原样**另存（`livp` 的 `.mov`、Android 动态照片的尾部 `MP4`），不重新编码；直接打开的视频文件也能导出。

## 📂 格式支持

- **静态**：`apng avif avifs blp bmp dds dib exr gif hdr heic heif ico icon jfif jp2 jpe jpeg jpg jxl jxr lep livp pbm pcx pfm pgm pic png pnm ppm psd psdt pxm qoi ras sr svg tga tif tiff webp wp2`
- **动态**：`gif webp png apng jxl avif`
- **实况**：`livp(IOS LivePhoto) jpg/heic/heif(Android MicroVideo/MotionPhoto)`
- **视频**（命令行/拖放/「打开」选中视频文件会进入独立播放器界面；不出现在同目录的翻页列表里）：`3gp avi evo flv m2ts m4v mkv mov mp4 mts mxf ts vob webm wmv`
- **音频**（同样进独立播放器界面，只是没有画面；不出现在同目录的翻页列表里）：`aac ac3 aif aiff amr ape au caf dsf dts flac m4a m4b mka mp2 mp3 mpc oga ogg opus tak tta w64 wav wma wv`
- **RAW**：`3fr ari arw bay cap cr2 cr3 crw dcr dcs dng drf eip erf fff gpr iiq k25 kdc mdc mef mos mrw nef nrw orf pef ptx r3d raf raw rw2 rwl rwz sr2 srf srw x3f`

## 🗃️ 特性

1. 🍀 全静态链接编译，原生绿色单文件，`v2.0` 起不再依赖 VC++ 运行库
2. ✅ 自动记忆上次窗口位置/大小，全屏、最大化状态与所在显示器一并记住（看图与播放器共用一份记忆）
3. ♟️ 图片透明区域使用国际象棋棋盘背景
4. 🖼️ 超大图也不卡：解码不阻塞界面，缩略图与相邻图片提前预读，画面静止后还会按显示分辨率重新采样一次，放大看文字、缩小看细密纹理都清晰
5. 🎨 ICC 色彩管理：按图像内嵌的配置文件转到当前显示器，宽色域图片不会偏色（可关闭）
6. 📖 支持读取开源 AI 生成图像的提示词信息【StableDiffusion WebUI、ComfyUI 输出的图像一般都会内嵌提示词参数或工作流 JSON，⚠ 若图像经过各大网络平台传播重新编码，该信息可能会被移除】
7. 🎞️ 实况照片与视频：内嵌视频可直接播放或原样导出，动图可逐帧浏览或分解成 PNG
8. ▶️ 简易播放器：命令行/拖放/「打开」选中视频或音频文件时进入独立播放界面（播放暂停、单击画面播放/暂停、进度条拖动与精确跳转、±5 秒与单帧步进、音量调节、按 `I` 看媒体信息；音频文件带实时频谱画面）
9. 🌏 六种界面语言：简体中文 / 繁體中文 / English / 日本語 / 한국어 / Русский，跟随系统或手动指定；支持浅色与深色主题
10. ⌨️ 常用操作几乎都有快捷键，设置页「帮助」里有一张速查表

## 💡 常见问题

**颜色看起来不对？**
程序默认开启 ICC 色彩管理，把图片按内嵌的配置文件转到当前显示器。极少数图片（例如整幅都是 Display P3 超饱和色的设计稿）超出 sRGB 的部分会被剪裁，图案可能看起来"糊成一片"——这是色彩管理的正常结果，不是转换错误。想按原始数值显示，可在设置页关掉「ICC色彩管理」。

**资源管理器里没有缩略图？**
到设置页「文件关联」勾选格式并应用。缩略图由随程序附带的 `JarkThumbnailProvider.dll` 提供，请确认它与主程序在同一个目录。

**启动时提示缺少 `VCOMP140.DLL`？**
那是 VC++ 运行库缺失，安装 [vc_redist.x64.exe](https://aka.ms/vs/18/release/vc_redist.x64.exe) 即可；`v2.0` 及以后的版本已不再依赖它。若仍报错，请确认下载的是正确版本。

**想看 AI 生图的提示词？**
按 `中键` 或 `TAB` 打开 EXIF 面板，StableDiffusion WebUI / ComfyUI 写入的提示词与工作流 JSON 会显示在里面（前提是图片传播时没有被平台重新编码）。

**内存占用会一直涨吗？翻页时为什么偶尔要等一下？**
不会。同时缓存的图片最多 10 张、并且合计不超过物理内存的一半（两个上限谁先到算谁），正在看的这张不会被淘汰，另外至少保留 2 张，所以往回翻一般不用重新解码。一张解码后好几个 GB 的巨幅图不会预读下一张（那样内存要翻倍），翻到它时等的那几秒就是解码本身的时间。按 `TAB` / `中键` 打开 EXIF 面板，顶部就是当前的缓存状况：`缓存: 9/10 张 · 3.18/16.0 GB` 与 `解码 12 · 淘汰 2 · 预取跳过 0`——"解码"是真正解过几张，翻页老是重新解码就会看到它一直涨。

**支持拖放吗？**
支持。把图片、视频或音频文件拖进窗口即可打开（同时拖入多个文件时只取第一个），打开后可以在同一目录里用左右方向键翻页；也可以把文件路径写在命令行上。

## 👋 快速上手

1. 下载最新版 [Releases](https://github.com/jark006/JarkViewer/releases)、[蓝奏网盘](https://jark006.lanzout.com/b0ko7mczg)、[百度云盘](https://pan.baidu.com/s/1ka7p__WVw2du3mnOfqWceQ?pwd=6666)，提取码：6666

2. 使用 `winget` 安装
```sh
winget install jark006.jarkviewer
```

3. 使用 `scoop` 安装
```sh
scoop bucket add extras
scoop install extras/jarkviewer
```

> ⚠️ 注意：自 `v2.0` 起，**不再依赖** `VC++运行库`，且可在 `PE` 环境直接运行。如果遇到"缺失 DLL"之类的错误，请确保下载了正确版本的程序。

## 🖥️ 系统兼容

✅ 支持 `64位` `Windows 10 ~ 11` 系统。（项目使用 `MSVC v145` 生成工具只保证兼容 `Win 10+`）

⚠️ 目前实测可以在 `64位` `Win 8/8.1` 稳定运行，但不保证未来版本也能继续兼容。

❌ 不兼容 `32位` `Win 7` 及以下系统。
