## 文档维护

- [中文 README](../README.md) / [English README](../README_EN.md) 面向使用者，保留功能、操作、格式与常见问题；开发内容从本目录进入。
- AGENTS.md 只放跨任务的工作规则和阅读入口。局部实现约束写到对应主题，并尽量由代码、自检或源码不变量检查守住。
- 一个事实只在一处详细说明，其余位置用链接。格式清单是例外：两份 README 必须与代码一致，由 `tools/check_source_invariants.ps1` 交叉检查。
- 文档和相关代码同轮更新；命令参数、库版本与结构体布局以当前源码/脚本为准。不要把一次实测耗时、断言总数或某台机器的路径当成永久约束。
- 历史报告只记录当时的版本、覆盖和结论。新一轮验证保留自己的报告，不向日常规则持续追加流水账；旧全文可从 Git 历史查回。

所有命令默认在仓库根目录执行，PowerShell 使用 `pwsh`。文档中的 `<图片>`、`<视频>`、`<报告目录>` 等是待替换参数；需要语料、GUI、ffmpeg 或本机工具链的命令应按前提运行。
