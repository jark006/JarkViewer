**JarkViewer** is a minimalist and lightning-fast image viewer for Windows. It opens everything from JPEG to the latest formats such as AVIF, HEIC and JPEG XL, and handles RAW, animated images, iOS Live Photos and Android Motion Photos smoothly. Videos and audio files go to a built-in standalone player with seeking, volume control, a live spectrum view and a media-info panel.

One portable executable, everything statically linked — just double-click it.

## ✨ Viewing images

| Action | How |
| --- | --- |
| Next / previous image | `Click/Wheel` on the left/right window edge, `←` `→`, `PgUp` `PgDn`, `Space` (next image when a still image is shown) |
| Zoom | `Wheel` in the window center, `↑` `↓`; `5` (numpad `5`) toggles between 1:1 and fit-to-window |
| Rotate | `Click/Wheel` on the top-left or top-right corner, `Q` `E` |
| Pan | Mouse drag, `W` `A` `S` `D` |
| Image info (EXIF) | `Middle click`, `TAB` or `I` |
| Fullscreen | `Double-click the window`, `F`, `F11` |
| Slideshow | `P` (`ESC` stops it); order and interval are in Settings |
| Frame-by-frame (animations) | Top control bar, `J` previous `K` pause/resume `L` next |
| First / last image | `Home` / `End` |
| Delete | `Delete` (moves to the recycle bin; the confirmation can be turned off in Settings) |
| Open an image | `Ctrl + O`, or drag a file into the window (when several are dropped only the first is used; you can page through the folder afterwards) |
| Copy image | `Ctrl + C` |
| Print | `Click` the bottom-left corner, `Ctrl + P` |
| Edit and annotate | `Ctrl + E` |
| Batch processing | `Ctrl + B` |
| Rename | `Ctrl + R` |
| Split an animation | `Ctrl + S` saves every frame as a separate PNG |
| Settings | `F1` General, `F2` File association, `F3` Help, `F4` About |
| Quit | `ESC`, `Ctrl + W` |

More handy bits:

- **Context menu**: copy EXIF info / file path / image data, export video, show EXIF, open file location, rename, copy or move to target folder, open with an external editor, move to recycle bin, file properties, print, edit, slideshow, batch, fullscreen, settings, about.
- **Thumbnail strip**: hover near the bottom edge and a strip of the folder's thumbnails unfolds — wheel or arrow keys to page, click to switch; it hides again when you move away.
- **Navigator (bird's-eye view)**: the bottom-right panel shows the whole image with the current visible area; drag the box to jump anywhere. Hide it with the `✕` on the panel (or from Settings) if you don't need it.

## 🎬 Player (video / audio)

Pick a video or audio file from the command line, drag-and-drop, or the Open dialog and a standalone player window appears (the image-viewing side is unaffected):

| Action | How |
| --- | --- |
| Play / pause | `Space`, or `click the picture` |
| ±5 seconds | `A` `D`, `←` `→` |
| Volume | `W` `S`, `↑` `↓`, `Wheel` |
| Single-frame stepping | `A` `D`, `←` `→` while paused (audio has no frames, so it jumps by 5 seconds) |
| Start / end | `Home` / `End` |
| Seek | Drag the progress bar (keyframe preview while dragging, exact landing on release) |
| Media info | `I` or `TAB` (path, size, duration, container, total bit rate, video/audio codec parameters) |
| Fullscreen | `Double-click the picture`, `F`, `F11` |
| Open another file | `Ctrl + O` (picking an image hands it back to the image viewer) |
| Quit | `ESC`, `Ctrl + W` |

- **Audio files have no picture**: the window shows the file name and path plus a column of **spectrum bars that dance in real time with the sound**, and the progress bar stays visible.
- **Playback stops on the last frame**; press `Space` to play again from the start. Drag the progress bar wherever you like — it lands exactly there.

## 🖨 Print / edit

`Ctrl + P` opens the print preview, where you can adjust `contrast`, `brightness` and `invert`, choose a color mode (`Color`, `Gray`, `Document`, `Dithering`), and then **Save As** another image file or **continue printing**.

1. **Document**: balances overall brightness, highlights text, and avoids the visual impact of local shadows. Suitable for printing images of photographed text documents.
2. **Dithering**: simulates pixel grayscale values using the distribution density of pure black pixels. This mode is suitable for dot-matrix and thermal printers and can also produce good image results.

`Ctrl + E` opens the editor and annotation tool: rectangle, ellipse, arrow, line, brush, mosaic and text, with color, line width, font size and fill; undo/redo, rotate/flip/invert and crop are there too. Save as a new file, copy to the clipboard, or overwrite the original (PNG keeps its alpha channel, transparent areas in JPG are flattened onto white).

## 🗂️ Batch processing

`Ctrl + B` processes the current folder's images in one go:

- **Convert format**: HEIC / AVIF / RAW and friends can be converted too — output to JPEG, PNG, WebP, BMP, TIFF…
- **Scale**: by percentage, by width, by height, custom size (stretchable), or limit the long edge (shrink only); the resampling algorithm defaults to Auto (area averaging when shrinking, Lanczos when enlarging)
- **Rotate / flip**
- **Rename** (prefix + index)
- Optional brightness, contrast and color-mode adjustments; output to a folder of your choice or in place, with or without overwriting existing files

## ✏️ File management and format association

- **Rename** (`Ctrl + R`): edits the base name only, keeping the extension; empty names, invalid characters, reserved device names and duplicates are all rejected.
- **Copy / move to target folder**: the destination can be switched at any time, duplicates are never overwritten (they get `name (2).ext`), and a cross-drive move degrades into copy + delete.
- **External editor**: hand the current image to a program of your choice (its path is configurable).
- **Move to recycle bin**: nothing is really deleted, and the confirmation prompt can be turned off in Settings.
- **Explorer thumbnails**: the bundled `JarkThumbnailProvider.dll` provides thumbnails for `JXL / AVIF / HEIC` and more in File Explorer. Tick the formats you want on the File association page and apply — file associations and thumbnails are registered together (the DLL is skipped automatically when it is not next to the executable).
- **File properties**: brings up the system properties dialog.

## 📹 Live Photos and video export

- **Live Photos**: iOS `livp` and Android MicroVideo / MotionPhoto (`jpg`/`heic`/`heif`) are all recognized; opening one plays it once and returns to the still image, and `Space` replays it at any time. Whether it makes sound is up to "Play Live Photo sound automatically" in Settings (silent by default).
- **Export video**: the "Export video" context menu item saves the embedded video **as-is** (`.mov` from `livp`, the trailing `MP4` of Android Motion Photos) with no re-encoding; opening a video file directly works too.

## 📂 Format Support

-   **Static**: `apng avif avifs blp bmp dds dib exr gif hdr heic heif ico icon jfif jp2 jpe jpeg jpg jxl jxr lep livp pbm pcx pfm pgm pic png pnm ppm psd psdt pxm qoi ras sr svg tga tif tiff webp wp2`
-   **Animated**: `gif webp png apng jxl avif`
-   **Live**: `livp (IOS LivePhoto) jpg/heic/heif (Android MicroVideo/MotionPhoto)`
-   **Video** (selecting a video file from the command line / drag-and-drop / "Open" enters the standalone player window; does not appear in the page-through list of its folder): `3gp avi evo flv m2ts m4v mkv mov mp4 mts mxf ts vob webm wmv`
-   **Audio** (same standalone player window, just without a picture; likewise does not appear in the page-through list): `aac ac3 aif aiff amr ape au caf dsf dts flac m4a m4b mka mp2 mp3 mpc oga ogg opus tak tta w64 wav wma wv`

## 🗃️ Features

1.  🍀 Fully static linking, a native portable single file — since `v2.0` it no longer depends on the VC++ runtime
2.  ✅ Remembers the last window position/size, plus the fullscreen/maximized state and the monitor it was on (one shared memory for the viewer and the player)
3.  ♟️ Chessboard background for transparent areas
4.  🖼️ Huge images stay responsive: decoding never blocks the UI, thumbnails and neighbouring images are preloaded, and once the view settles the visible area is resampled at display resolution — text when zooming in and fine textures when zooming out stay crisp
5.  🎨 ICC color management: converts from the image's embedded profile to the current monitor, so wide-gamut images don't shift color (can be turned off)
6.  📖 Supports reading prompt parameter information from open-source AI-generated images. Images output by StableDiffusion WebUI and ComfyUI typically contain embedded prompt parameters or workflow JSON. However. ⚠ if the images are re-encoded through circulation on various online platforms, this information may be removed.
7.  🎞️ Live Photos and video: the embedded video can be played or exported as-is; animations can be stepped through or saved as individual PNG frames
8.  ▶️ Simple player: selecting a video or audio file from the command line / drag-and-drop / "Open" enters a standalone player window (play/pause, click the picture to toggle, draggable progress bar with exact seeking, ±5s and single-frame stepping, volume, press `I` for media info; audio files get a live spectrum view)
9.  🌏 Six UI languages — Simplified Chinese / Traditional Chinese / English / Japanese / Korean / Russian — following the system or set manually, with light and dark themes
10. ⌨️ Almost everything has a shortcut; the Help page in Settings has a cheat sheet

## 💡 FAQ

**The colors look wrong?**
ICC color management is on by default: images are converted from their embedded profile to the current monitor. A few images (say, a design full of Display P3 super-saturated colors) get clipped where they leave the sRGB gamut and may look "flattened" — that is the correct result of color management, not a conversion bug. Turn off "ICC Color Management" in Settings to see the raw values instead.

**No thumbnails in File Explorer?**
Tick the formats you want on the File association page in Settings and apply. Thumbnails come from the bundled `JarkThumbnailProvider.dll`, so make sure it sits next to the main executable.

**Startup complains about a missing `VCOMP140.DLL`?**
That is a missing VC++ runtime — install [vc_redist.x64.exe](https://aka.ms/vs/18/release/vc_redist.x64.exe). Versions from `v2.0` on no longer need it. If the error persists, double-check that you downloaded the right build.

**Where are the AI generation prompts?**
Press `middle click` or `TAB` to open the EXIF panel; prompts and workflow JSON written by StableDiffusion WebUI / ComfyUI show up there (as long as the image was not re-encoded while circulating online).

**Does it support drag-and-drop?**
Yes — drop an image, video or audio file onto the window to open it (when several files are dropped together only the first is used), then page through the same folder with the arrow keys. You can also pass a file path on the command line.

## 👋 Quick Start

1. Download the latest version at [Releases](https://github.com/jark006/JarkViewer/releases), [Lanzou Cloud](https://jark006.lanzout.com/b0ko7mczg), or [Baidu Cloud](https://pan.baidu.com/s/1ka7p__WVw2du3mnOfqWceQ?pwd=6666) (extraction code: 6666).

2. Install by `winget`
```sh
winget install jark006.jarkviewer
```

3. Install by `scoop`
```sh
scoop bucket add extras
scoop install extras/jarkviewer
```

> ⚠️ Note: since `v2.0`, JarkViewer **no longer depends** on the `VC++ Runtime` and can run directly in `PE` environments. If you still hit a "missing DLL" error, please make sure you downloaded the correct version.

## 🖥️ System Compatibility

✅ Supports `64-bit` `Windows 10 ~ 11`. (The project uses `MSVC v145` toolset and only guarantees compatibility with `Win 10+`)

⚠️ Currently tested to run stably on `64-bit` `Win 8/8.1`, but future versions are not guaranteed to remain compatible.

❌ Not compatible with `32-bit` `Win 7` and earlier systems.
